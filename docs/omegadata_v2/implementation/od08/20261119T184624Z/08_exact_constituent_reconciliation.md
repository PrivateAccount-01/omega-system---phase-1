# Exact identities, not counts
Reconciliation returns expected-minus-actual, actual-minus-expected, matching identities, duplicates and unresolved revisions. Same-count wrong sets fail. Unknown symbols cannot substitute for mismatched securities. Expected control sets are explicit literal tuples in tests, never generated by the production query.

Every selected revision has exactly one primary decision. Included, excluded, unresolved, blocked, conflicting and provisional decisions reconcile to selected count. Research/liquidity/tradability/execution diagnostics accompany the primary decision. Exclusion never erases underlying membership. Complete selected accounting cannot certify source coverage.
