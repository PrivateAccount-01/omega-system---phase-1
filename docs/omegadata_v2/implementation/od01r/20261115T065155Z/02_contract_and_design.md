## Reuse and minimal contracts

Retain frozen Pydantic v1 records, revision hashing, strict parsing, explicit provider injection and ContextVar scopes. Reuse stdlib urllib.parse/pathlib/hashlib. No new schema fields or dependencies. Extend with a shared URL preflight returning a typed HOST_NOT_ALLOWED refusal: HTTPS only, absent port or canonical :443, no credentials, control characters, whitespace, backslash, percent-encoded authority, empty/malformed authority, IP literals or non-DNS forms. Exact lowercase/trailing-dot DNS normalization remains; no domain wildcard expansion. Local names are denied unless explicitly listed, and IP literals are never supported by v1. HTTP (including current GDELT technical metadata) remains blocked; a future separately approved contract is required. Validate before client/temp creation. Redirect/DNS/address egress control remains OD-02.

Cache: READ_CACHED still precedes any manifest read. Canonically confine latest pointer, artifact and optional manifest references to the selected raw/seed root and source/year/month partition before opening. Reject traversal, drive-relative/UNC/device/ADS forms, symlink/junction escapes, empty/ambiguous paths, malformed/duplicate JSON keys, wrong source/date, checksum and length mismatch. Keep safe absolute paths within the selected partition, repository-relative legacy paths and bare partition filenames. Check identity metadata when present; old missing identity is accepted only in the source/date-specific pointer namespace with valid checksum. Invalid manifests produce cache miss; no bytes outside the root may be opened. No old cache rewritten. Race-free descriptor traversal/atomic storage/concurrent hostile filesystem mutation remains OD-04/14.

## Trust, review and verification

Canonical hash is consistency only, not human attestation. All 13 production policies stay PENDING_REVIEW. Trusted administrator must independently review original terms, scoped source/operation/transport/host/purpose, finite validity and digest, and retain signoff/revision checkpoints outside repository control. No live operation may be enabled by editing JSON strings alone; deployment/source job enablement requires that external record and separate user authorization. Cryptographic approver verification is not implemented here.

Write negative tests first against unchanged production; save expected failures with zero-side-effect spies and harmless sentinels. Then minimal patch, unchanged expectations, legacy 100 tests, complete offline suite, collection, Ruff/mypy/pip. Use new runner labels; fail on overwrite. Runner adds disposable write/SQLite guards beyond OD-01 socket/subprocess denial. Internal Windows socketpair is narrowly allowed; this is an accidental-side-effect harness, not a malicious Python-code sandbox. No extra runtimes/packages installed. Same-model AEF roles do not constitute independent human/security/financial approval. OD-01R technical pass never grants publication readiness.
