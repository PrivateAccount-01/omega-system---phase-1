# Upstream admission

[admission.py](source/src/omegadata/canonical_storage/admission.py) pins exact parser metadata, OD06 identity/calendar, OD07 proof/context/result, OD08 complete decision snapshots, and OD09 source/comparison/review/reprocess contracts. A ParsedResult receipt never grants financial authority. Authentic parser rows cannot be retained under this code-only capability; metadata-only receipts remain reusable.

Derived volume replays the OD07 bound proof and binds exact consumed value, observation, source row/artifact, security/listing/venue/session, currency/basis and upstream digests. Universe snapshots replay the exact context and preserve excluded/unresolved entries. Reconciliation strict scopes independently select required persisted observations by source/listing/field/session/cutoff; unknown availability refuses and future-known rows cannot enter earlier contexts. Publisher/reported identifier/lineage/financial-field metadata are bound to exact source-observation digests. Tolerance quality stays provisional unless independently authorized.

The final negative test reproduced a metadata payload rights bypass. Recursive bounded admission now refuses denied/non-canary evidence and parser financial rows before any transaction. Caller labels cannot grant real source access. Non-market records always remain financially ineligible.
