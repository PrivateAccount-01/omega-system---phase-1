# Pre-code reference-verifier contract

OD05R only. New standalone reference_evidence.py and era_matrix.py; existing OD05 interfaces, policies and routes unchanged. Extend stdlib/Pydantic, no package or provider dependency.

The immutable envelope has strict, bounded, duplicate-free JSON metadata; explicit document identity, source/CM scope, issuer/version/URL/acquisition provenance, date applicability, declared permissions, field/section semantics and optional sample identity. Document/sample blobs remain separately supplied local bytes. Exact hashes and lengths establish identity only. Metadata permission/reviewer labels are claims, never a trusted approval capability. No official-promotion authority is provisioned in this phase: even a caller claiming original bytes plus an owner label remains authenticity/reference pending. This is an explicit fail-closed boundary, not verification of that owner claim. A later trusted human review ingestion mechanism needs a separate design and tested authority root.

ExpectedCorpus independently pins index SHA, nonzero reference count and exact document/sample names, SHA and lengths. Loader is read-only, flat allowlisted files, bounded counts/bytes, rejects unsafe components and all links/reparse points; missing, empty or moved corpus fails. Pure verify_reference performs no I/O. Public errors contain code only. Canonical digest version od05r.semantic/v1 excludes operational acquisition/review times but binds all scope, original identity, schema/version, legal claim, semantics and applicability fields. Raw metadata SHA retains operational timestamp changes. No time-of-knowledge inference.

States preserve discovered/bytes-unverified/hash-verified/schema-pending/row-pending/blocked-rights/conflict/unknown distinctions; SCHEMA_EVIDENCE_VERIFIED, ROW_REFERENCE_VERIFIED and OFFICIAL_REFERENCE_VERIFIED are deliberately unreachable without authenticated out-of-band review capabilities. Output explicitly reports original-byte identity separately from original authenticity. Era cells retain reference identities/versions and conflicting or overlapping applicability; supported is always false until genuine reference gates exist. No automatic year-based routing.

Tests R01–R24 and independent stdlib oracle are authored/frozen before application files. API absence is a feature gap, not legacy-defect evidence. Runtime matrix uses the previously audited offline guard, fresh sanitized native-filesystem copies, three existing interpreters, full suites, lint/type/pip/compile, exact source/fixture hashes and OS skip pairing. No service/browser/container startup is needed for this offline library. Guard negatives and bounded resource measurements are separate experiments. Any later additions keep actual chronology.

F01–F12: all BLOCKED_REFERENCE at entry. No authenticated publisher bytes, human reference-use permission, reviewed original sample or field-level expected rows supplied. F01 original SHA; F02 real ZIP/member/schema; F03 era; F04 date semantics; F05 prices; F06 volume; F07 ordinal; F08 identity; F09 optional fields; F10 expected rows; F11 invalid-format negatives; F12 replay/rights/lineage each require that authentic corpus. Synthetic verifier tests cannot substitute. No official parser extension is planned absent those gates.
