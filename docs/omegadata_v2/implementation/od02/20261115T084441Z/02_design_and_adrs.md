# OD-02 design gate (same-model Maker/Reviewer)

Baseline feature HEAD 3b5c0fffdd5ecd28a9318a51b43784d3ba133dcc. OD-01R technical PASS and final QA verified; current ten-file patch matches its reviewed binary diff. Known prior-phase changes are owned work from this conversation, not unknown user edits. Layer only bounded OD-02 hunks; preserve every OD-01R report and unrelated hunk. No git mutation or source enablement.

Design: extend existing DownloadManager, httpx and stdlib; a small acquisition module supplies typed failures, explicit validated resource limits, a single ContextVar job budget and bounded source-era validators. Strict acquisition success is evaluated at public download/probe boundaries; a private transport candidate is HTTP_RECEIVED until validation, allowing isolated transport tests without pretending arbitrary bytes are an archive. Existing policy decisions remain prerequisites and refresh at transport/store boundaries. No new permissions or dependency.

Initial explicit resource profile (not legal source permissions): 5 total requests, 30s total deadline, 8s request timeout, 8 MiB response, 32 MiB archive expansion, 8 entries, compression ratio 100, 20,000 rows, zero redirects, deterministic bounded backoff. Missing/extra/invalid configuration refuses. Values are conservative offline engineering ceilings, not evidence of provider entitlement or guaranteed adequacy for every historical archive. Larger/unknown formats quarantine pending separately reviewed limits. One job scope includes discovery, bootstrap, profiles and selected adapters; nested scopes reuse budget, never reset it. Fake clock/sleeper supported. 401/403/451/429/404/redirect, TLS, policy, structural and resource failures are terminal; selected 5xx/timeouts alone may retry within shared budget.

Redirect decision: reject ALL 3xx including allowed-to-allowed, before any second request; HTTPX follow_redirects=False, urllib/curl automatic network paths disabled. TLS verification/proxy environment cannot be relaxed. Without demonstrated connection-time DNS pinning/OS egress control, actual provider transports remain BLOCKED_EXTERNAL_EGRESS. Explicit HTTPX MockTransport and explicit offline adapter callbacks serve synthetic tests only; no environment-wide allow switch or approved-source default. Python callback injection is trusted application/test code, not a sandbox against arbitrary malicious Python. The no-socket/subprocess test harness remains independent.

NSE legacy/new CSV ZIP validators use repository column mappings/era metadata, exact request date, complete ZIP central directory, deterministic expected member name, safe names, no encryption/nesting/duplicates, bounded sizes/ratio/member count/rows, strict UTF-8(-BOM), required unique headers/field count, finite nonnegative prices/volume, OHLC range and duplicate security/date keys. BSE modern dated CSV/ZIP and legacy ZIP date in its expected member filename supported; unknown or unprovable eras reject SCHEMA_UNKNOWN. Synthetic fixtures validate interpretation of repository mappings, not independent official authenticity: SOURCE_REFERENCE_PENDING until human review. JSON endpoints reject HTML/login/error/missing-index and malformed/empty shapes. Unimplemented sidefeed semantics cannot claim financial/date validation.

Evidence: append byte SHA-256 independently of legacy registry checksum, source/request date/era/schema, HTTP status/type/transport, sanitized original/final URL, policy decisions, actual request count and stage/source mode. Preserve exact raw bytes; no OD-04 atomic/immutable storage claim. Tests use disposable outputs. Cache and seed are explicitly distinct; cache-only miss never fetches. No existing dataset/release pointer is rewritten.

Edit budget: new acquisition module and resource config; DownloadManager and canonical probe integration; standalone F&O caller must not bypass the offline gate; new OD-02 tests. Implementation review selected unconditional BLOCKED_EXTERNAL_EGRESS before its legacy GET, retaining the existing policy checks, rather than falsely certifying an unimplemented F&O validator through the manager. Only narrow legacy test fixture adaptations if stricter acquisition validation demands a valid synthetic archive or an explicit offline runner: preserve purpose/assertions and report any change. No financial math, warehouse, release, signing, CI/dependency edits. Any unexpected dirty overlap stops before edit.

Same-model adversarial design review: challenge every nested catch, bootstrap/discovery denial, response URL mismatch, redirect/cookie forwarding, max body/ZIP expansion before read, active policy before store, attempts/deadline counting, context isolation and original-byte preservation. Negative-first proofs must precede corresponding production changes. No independent human/legal/security consensus claimed. OD-03/04 not started.
